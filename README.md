# Calcly Suit — web version 1.2.0

Calculator suite by Zocxorian Technologies: standard and scientific calculator, everyday, finance, date & time tools (Hijri date, burj and Abjad in the age calculator) and 10 unit converters.

- Live: https://zocxor.github.io/Calcly/ (after GitHub Pages is switched on)
- Android app: https://play.google.com/store/apps/details?id=com.zocxorian.calclysuit
- Works offline after the first visit and can be installed as an app from the browser menu.
- Everything you type stays in your browser. Nothing is uploaded.

`calcly-suite-pwa.zip` is the first web version (September 2026), kept for reference.
